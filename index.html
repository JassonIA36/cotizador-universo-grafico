Acciones de Sincronización

La app sincroniza automáticamente tus cambios tras cada guardado y cada 60 segundos si tienes conexión. También puedes forzar la sincronización manual ahora:

📌 ¿Cómo activar la base de datos en Cloudflare?

1. En tu panel de Cloudflare ve a Storage & Databases > D1 y crea la base de datos ug-cotizador-db.
2. En la pestaña Console ejecuta el archivo schema.sql.
3. En tu proyecto de Cloudflare Pages > Settings > Functions vincula el D1 con el nombre DB.
